        How it works

        The frames come from HeiPorSPECTRAL: porcine organs imaged at 100 wavelengths from 500 to 1000 nm. Each pixel's spectrum is normalised, optionally reduced to 16 bands that simulate a snapshot mosaic sensor, and classified into one of 20 organs by a 29k–40k-parameter network exported to ONNX. Everything runs here: the cube, the preprocessing and the model are downloaded once and nothing is sent to a server.

        The preprocessing is a TypeScript port of the Python pipeline. A test runs both on the same frames and requires the same inputs (max difference about 1e-6) and the same predictions (at least 99.9% of pixels).

        Results on two test pigs never used for training: macro F1 0.751 with the full spectrum and 0.713 with 16 bands for this model. A spatial patch CNN reached 0.802 / 0.786 but is 4–5× slower on a CPU, and this demo is built for speed. Kidney is mostly confused with liver; its frame is included on purpose.

        Limits: one organ is annotated per frame, so predictions outside the white outline are never scored; the model has no background class; the 16-band sensor is simulated by spectral binning only; the data are porcine and the model is not clinically validated.
